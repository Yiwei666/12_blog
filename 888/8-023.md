## 1. `.cache\codex-runtimes`目录

### 1. 目录概况

`C:\Users\31598\.cache\codex-runtimes` 主要存放 Codex 执行本地任务所需的运行环境和依赖工具，例如 Python、Node.js、Git，以及处理表格、文档、PDF 的相关组件。它们需要反复使用，所以不会在每次任务结束后全部删除。

目前该目录主要有以下3类内容：

| 内容 | 用途 | 是否需要长期保留 |
|---|---|---|
| `codex-primary-runtime` | 当前正在使用的运行环境 | 需要 |
| `codex-runtime-install-*` | 下载、解压运行环境时的临时安装目录 | 安装完成后通常不需要 |
| `codex-primary-runtime.previous-*` | 更新时留下的旧版目录 | 新版正常后通常不需要 |


### 2. 迁移/验证命令

先完全退出 Codex，再从开始菜单打开“Windows PowerShell”，执行下面整段命令。

注意：可以先创建 `D:\software\21_codex\02_CodexCache` 目录，但不要创建最后一级 `codex-runtimes` 文件夹。


```sh
$ErrorActionPreference = 'Stop'

$source = 'C:\Users\31598\.cache\codex-runtimes'
$destination = 'D:\software\21_codex\02_CodexCache\codex-runtimes'

# 检查原目录
$sourceItem = Get-Item -LiteralPath $source
if (-not $sourceItem.PSIsContainer) {
    throw '原路径不是文件夹，停止迁移。'
}
if ($sourceItem.Attributes -band [IO.FileAttributes]::ReparsePoint) {
    throw '原目录已经是联接或链接，停止迁移，请先检查。'
}

# 防止覆盖 D 盘已有内容
if (Test-Path -LiteralPath $destination) {
    throw 'D 盘目标目录已经存在，停止迁移，请先检查。'
}

# 创建父目录，并将运行环境搬到 D 盘
New-Item -ItemType Directory -Path 'D:\software\21_codex\02_CodexCache' -Force | Out-Null
Move-Item -LiteralPath $source -Destination $destination

# 在 C 盘原位置建立目录联接
New-Item -ItemType Junction -Path $source -Target $destination
```

等待执行结束，再运行以下命令验证：

```sh
Get-Item -LiteralPath 'C:\Users\31598\.cache\codex-runtimes' | Select-Object FullName, LinkType, Target
```

# 2. Tecent

## 1. `AppData\Roaming\Tecent`目录

### 1. 目录概况

**1️⃣. Roaming目录**

1. `C:\Users\...\AppData\Roaming`（系统环境变量简写为 `%APPDATA%`）是 Windows 中专门用于存放应用程序的用户配置、个性化偏好设置及核心用户数据的文件夹。

2. 在局域网企业网域环境下，Windows 支持“漫游用户配置文件”。当你在公司的电脑 A 上设置好软件并下班登出后，`Roaming` 目录内的所有文件会被同步上传到服务器；第二天你在电脑 B 上登录同一个域账号，系统会自动将这些配置拉取下来。

3. 虽然大部分个人用户的电脑没有加入企业域，但现代软件开发遵循微软的规范：凡是轻量、重要、希望随账号迁移的配置，都会统一存放在 `Roaming` 中。






### 2. 迁移备份命令

1. 完全退出微信、QQ、腾讯会议等腾讯软件，包括系统托盘中的程序。
2. 开始菜单搜索 `Windows PowerShell → 右键 → 以管理员身份运行`。
3. 复制从开头 `& { 到最后一个 }` 的全部代码；不要复制后面的中文提问，也不要复制 Markdown 的代码框标记。
4. 粘贴后，如果没有自动开始，按一次 `Enter`。
5. 这段命令会复制并校验文件，建立目录联接，同时保留 C 盘原副本。复制使用 Windows 10 自带的 `Robocopy`。


```sh
& {
    $ErrorActionPreference = 'Stop'

    $source = 'C:\Users\31598\AppData\Roaming\Tencent'
    $destination = 'D:\software\23_NTFS_AppData\01_Roaming\Tencent'
    $backup = 'C:\Users\31598\AppData\Roaming\Tencent.before-move'

    # 检查相关程序是否已经退出
    function Assert-TencentClosed {
        $running = @(Get-Process | Where-Object {
            $_.ProcessName -match '^(Weixin|WeChat.*|QQ.*|TIM|TXPlatform|TXSSO.*|wemeet.*|WeMeet.*|Tencent.*)$' -or
            $_.Path -match '\\Tencent\\'
        })

        if ($running.Count -gt 0) {
            throw ('请完全退出这些腾讯程序后再运行：' +
                (($running.ProcessName | Sort-Object -Unique) -join ', '))
        }
    }

    Assert-TencentClosed

    # 检查原目录，防止重复迁移或覆盖已有数据
    $sourceItem = Get-Item -LiteralPath $source -Force

    if (-not $sourceItem.PSIsContainer -or
        ($sourceItem.Attributes -band [IO.FileAttributes]::ReparsePoint)) {
        throw '原路径不是普通文件夹，停止迁移。'
    }

    if ((Test-Path -LiteralPath $destination) -or
        (Test-Path -LiteralPath $backup)) {
        throw '目标目录或备份目录已经存在，停止迁移，请先检查。'
    }

    $entries = @(Get-ChildItem -LiteralPath $source -Force -Recurse)

    if (@($entries | Where-Object {
        $_.Attributes -band [IO.FileAttributes]::ReparsePoint
    }).Count -gt 0) {
        throw '原目录内部含有链接，需要单独检查，停止自动迁移。'
    }

    # 复制文件，保留属性、时间和访问权限
    New-Item -ItemType Directory -Path (Split-Path -Parent $destination) -Force |
        Out-Null

    Write-Host '正在复制到 D 盘，请保持腾讯软件关闭……'

    & robocopy.exe $source $destination /E /COPY:DATS /DCOPY:DAT /R:1 /W:1 /XJ /NP /NFL /NDL

    if ($LASTEXITCODE -ge 8) {
        throw '复制失败，C 盘原目录保持原样。请保留报错，勿继续迁移。'
    }

    # 校验目录结构及每个文件的内容
    Assert-TencentClosed
    Write-Host '正在校验文件内容，请等待……'

    $copiedEntries = @(Get-ChildItem -LiteralPath $destination -Force -Recurse)

    if ($entries.Count -ne $copiedEntries.Count) {
        throw '文件或目录数量不一致，停止切换；C 盘原目录保持原样。'
    }

    $checked = 0

    foreach ($entry in $entries) {
        $relative = $entry.FullName.Substring($source.Length + 1)
        $copiedItem = Get-Item -LiteralPath (Join-Path $destination $relative) -Force

        if ($entry.PSIsContainer -ne $copiedItem.PSIsContainer -or
            ($copiedItem.Attributes -band [IO.FileAttributes]::ReparsePoint)) {
            throw "目录结构校验失败：$relative"
        }

        if (-not $entry.PSIsContainer) {
            if ($entry.Length -ne $copiedItem.Length -or
                (Get-FileHash -LiteralPath $entry.FullName -Algorithm SHA256).Hash -ne
                (Get-FileHash -LiteralPath $copiedItem.FullName -Algorithm SHA256).Hash) {
                throw "文件内容校验失败：$relative"
            }
        }

        $checked++

        if ($checked % 100 -eq 0) {
            Write-Progress -Activity '校验迁移内容' `
                -Status "$checked / $($entries.Count)" `
                -PercentComplete (100 * $checked / $entries.Count)
        }
    }

    Write-Progress -Activity '校验迁移内容' -Completed

    # 保留 C 盘原副本，再建立目录联接
    Assert-TencentClosed
    Rename-Item -LiteralPath $source -NewName (Split-Path -Leaf $backup)

    try {
        New-Item -ItemType Junction -Path $source -Target $destination |
            Out-Null
    }
    catch {
        # 建立联接失败且原位置为空时，恢复原目录名称
        if (-not (Test-Path -LiteralPath $source)) {
            Rename-Item -LiteralPath $backup -NewName 'Tencent'
        }
        throw
    }

    # 显示迁移结果
    Get-Item -LiteralPath $source |
        Select-Object FullName, LinkType, Target |
        Format-List

    Write-Host '联接已建立。' -ForegroundColor Green
    Write-Host "C 盘原副本保留在：$backup"
    Write-Host '请验证腾讯软件运行和已有数据，确认正常后再清理原副本。'
}
```


### 3. 删除备份

```sh
& {
    $ErrorActionPreference = 'Stop'

    $source = 'C:\Users\31598\AppData\Roaming\Tencent'
    $destination = 'D:\software\23_NTFS_AppData\01_Roaming\Tencent'
    $backup = 'C:\Users\31598\AppData\Roaming\Tencent.before-move'

    # 必须已经正确建立目录联接
    $link = Get-Item -LiteralPath $source -Force

    if ($link.LinkType -ne 'Junction' -or
        @($link.Target)[0] -ine $destination) {
        throw '迁移联接未建立或目标不正确，停止清理。'
    }

    if (-not (Test-Path -LiteralPath $destination -PathType Container)) {
        throw 'D 盘目标目录不存在，停止清理。'
    }

    # 备份必须是指定位置的普通文件夹
    $backupItem = Get-Item -LiteralPath $backup -Force

    if ($backupItem.FullName -ine $backup -or
        -not $backupItem.PSIsContainer -or
        ($backupItem.Attributes -band [IO.FileAttributes]::ReparsePoint)) {
        throw '备份目录状态异常，停止清理。'
    }

    $internalLinks = @(Get-ChildItem -LiteralPath $backup -Force -Recurse |
        Where-Object {
            $_.Attributes -band [IO.FileAttributes]::ReparsePoint
        })

    if ($internalLinks.Count -gt 0) {
        throw '备份内部含有链接，停止自动清理。'
    }

    Remove-Item -LiteralPath $backup -Recurse -Force
    Write-Host 'C 盘迁移备份已删除。'
}
```
