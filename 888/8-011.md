## 3. Sublime text

### 1. md文件大纲视图预览

你可以安装“Outline”插件来实现右侧实时大纲视图。具体步骤如下：

1. 打开 Sublime Text，按 `Ctrl+Shift+P` 调出命令面板，输入 `Package Control: Install Package`，回车。

2. 在搜索框中输入 `Outline` 并回车安装即可。

3. 安装完成后，再次按下 `Ctrl+Shift+P`，输入 `Browse Mode: Outline (Right)` 并回车，就会在编辑窗口右侧出现大纲面板，自动列出当前 Markdown 文件中的所有 # 标题，编辑时会实时更新。

4. 关闭大纲视图时，点击面板右上角的关闭按钮，或按 `Shift+Alt+1` 恢复单窗格布局即可。

5. 再次打开大纲视图，只需按 `Ctrl+Shift+P` 调出命令面板，输入并选择 “Outline: Toggle Outline (Right)”（或直接输入“Outline”找到相应命令）即可在右侧重现大纲。

▶️ **Ignore X-Frame-Options Header**

`Ignore X-Frame-Options Header` 是一个专门用于解除浏览器“防网页嵌套”限制的开发者辅助扩展（在 Firefox 附加组件商店和 Chrome 应用商店均有提供）。它的核心功能是在网络请求到达浏览器渲染引擎之前，强行剥离服务器返回的防嵌套安全响应头，从而允许任意网站被 `<iframe>` 框架嵌入显示。

背景：通过 waybacktweets 工具将所有备份打包生成了一个本地 HTML，试图在一个页面里集中看；但由于该文件内部是用 `<iframe>`（画中画框架）加载每条推特快照的，直接撞上了 Twitter 官方的防嵌套策略，导致 Firefox 满屏弹窗拦截、内容一片空白。

安装并启用它之后，Firefox 不会再拦截这些内嵌框架。你下载的 HTML 文件里的每一条推文（包括推文里的配图）都能直接在当前页面正常渲染展开。你只需像刷朋友圈或翻相册一样一直往下滑动，就能快速筛出目标图片，免去了手动点击几百次链接的繁琐过程。


▶️ **Linkclump Pro**

Linkclump Pro 是一个“框选多个链接，一次打开”的浏览器扩展。

按住键盘上的 Z 键，同时按住鼠标左键并拖动，用框选中想打开的链接。松开鼠标左键后，选中的链接就会在新标签页中打开。
