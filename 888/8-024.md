# 手机

## 1. 小米

### 1. 小米12X

小米 12X 的核心配置是 6.28 英寸屏幕、骁龙 870、176g 机身、4500mAh 电池和 67W 有线快充。

主要硬件规格：

| 项目 | 小米 12X 详细参数 |
|---|---|
| 长 × 宽 × 厚 | **152.7 × 69.9 × 8.16 mm** |
| 重量 | **176g** |
| 处理器 | **高通骁龙 870**，7nm 制程 |
| CPU | 八核 Kryo 585：1×3.2GHz + 3×2.42GHz + 4×1.8GHz |
| GPU | Adreno 650 |
| 内存 | LPDDR5；国行提供 8GB、12GB |
| 存储 | UFS 3.1；128GB、256GB |
| 屏幕 | 6.28 英寸 AMOLED，双曲面、中置挖孔 |
| 分辨率 | 2400 × 1080，约 419 PPI，20:9 |
| 刷新率 | 最高 **120Hz** |
| 触控采样率 | 最高 480Hz |
| 屏幕色彩 | 12bit 色深、DCI-P3 广色域，支持 HDR10+ |
| 屏幕保护玻璃 | 康宁 Gorilla Glass Victus |
| 电池容量 | **4500mAh，典型值** |
| 有线充电 | **67W**；官方实验室数据约 39 分钟充满，实际时间受环境和使用状态影响 |
| 散热 | 2600mm² VC 液冷散热 |
| 出厂系统 | **MIUI 13，基于 Android 11** |


相机为后置三摄，具体如下：

| 相机项目 | 详细参数 |
|---|---|
| 后置主摄 | **5000 万像素，索尼 IMX766**；1/1.56 英寸传感器，f/1.88，支持 **OIS 光学防抖** |
| 超广角 | **1300 万像素**，123° 视野，f/2.4 |
| 长焦微距 | **500 万像素**，f/2.4，支持约 3–7cm 自动对焦 |
| 前置自拍 | **3200 万像素**，f/2.45 |
| 后置录像 | 最高 **8K 24fps**；支持 **4K 30/60fps** |
| 常用拍摄功能 | 夜景、人像、专业模式、长曝光、慢动作等 |


其他功能和接口：

| 项目 | 支持情况 |
|---|---|
| 移动网络 | 5G，支持 SA / NSA；双 Nano-SIM 卡，具体频段因地区版本而异 |
| Wi-Fi / 蓝牙 | Wi-Fi 6、蓝牙 5.1 |
| NFC / 红外遥控 | 均支持 |
| 定位 | 支持 GPS L1+L5 双频、北斗、Galileo、GLONASS 等 |
| 解锁 | 屏下指纹、面部解锁 |
| 扬声器 | 对称式立体声双扬声器，哈曼卡顿调音、杜比全景声 |
| 振动马达 | X 轴线性马达 |
| 数据接口 | USB Type-C，USB 2.0 |
| 3.5mm 耳机孔 | 不支持 |
| microSD 存储卡 | 不支持 |
| eSIM | 不支持 |
| 无线充电 | **不支持** |
| 防水 | 没有官方 IP 防水等级认证 |


### 2. 小米8

小米 8 的核心配置是 骁龙 845、6.21 英寸 AMOLED 屏幕、175g 机身、3400mAh 电池和后置双 1200 万像素相机。

| 项目 | 小米 8 标准版详细参数 |
|---|---|
| 长 × 宽 × 厚 | **154.9 × 74.8 × 7.6mm** |
| 重量 | **175g** |
| 机身材质 | 四曲面玻璃后盖、7000 系铝合金中框 |
| 配色 | 黑色、蓝色、白色、金色 |
| 处理器 | **高通骁龙 845**，八核，最高主频 2.8GHz |
| GPU | **Adreno 630**，最高频率 710MHz |
| 内存 | LPDDR4X 双通道；首发为 **6GB** |
| 存储 | **64GB / 128GB / 256GB**，UFS 2.1 |
| 屏幕 | **6.21 英寸三星 AMOLED**，刘海设计、平面显示屏 |
| 分辨率 | **2248 × 1080**，402 PPI，18.7:9 |
| 刷新率 | **60Hz** |
| 屏幕亮度 | 典型 430nit，高亮模式 HBM 600nit |
| 显示功能 | DCI-P3 广色域、HDR、AOD 息屏显示、护眼模式、色温调节 |
| 电池 | **3400mAh 典型容量**，内置不可拆卸 |
| 有线充电 | 支持 **QC4+**；原装配备 **18W QC3.0 充电器** |
| 无线充电 | **不支持** |
| 初始系统 | **MIUI 9.5，基于 Android 8.1**；后续通过更新升级 |


相机采用“主摄＋长焦”组合：

| 相机项目 | 详细参数 |
|---|---|
| 后置主摄 | **1200 万像素，索尼 IMX363**；f/1.8，1.4μm 像素，支持 **四轴 OIS 光学防抖**、Dual PD 双核对焦 |
| 后置长焦 | **1200 万像素**，f/2.4，支持约 **2 倍光学变焦**及人像拍摄 |
| 超广角相机 | 没有独立超广角镜头 |
| 前置自拍 | **2000 万像素**，支持 AI 美颜、人像背景虚化、HDR |
| 后置录像 | 原始官方参数标注 **4K 30fps**，另支持 1080p、720p 录像 |
| 慢动作 | 支持 720p / 1080p 240fps；后续系统加入 960fps 超慢动作 |
| 其他功能 | AI 场景识别、人像模式、全景、HDR；后续系统加入手持超级夜景等功能 |

其他连接、解锁和接口功能如下：

| 项目 | 支持情况 |
|---|---|
| 移动网络 | **4G 全网通，不支持 5G** |
| SIM 卡 | 双 Nano-SIM，双卡双待 |
| Wi-Fi | Wi-Fi 5，802.11 a/b/g/n/ac；支持 2.4GHz、5GHz |
| 蓝牙 | **Bluetooth 5.0** |
| NFC | 支持 |
| 定位 | **GPS L1＋L5 双频定位**；另支持北斗、GLONASS、Galileo、QZSS |
| 指纹解锁 | **后置指纹** |
| 人脸解锁 | **红外人脸识别**；标准版没有透明探索版的 3D 结构光 |
| 红外遥控 | **不支持**；红外人脸识别不能用来遥控家电 |
| 扬声器 | 底部单扬声器 |
| 数据接口 | USB Type-C，USB 2.0，支持 OTG |
| 3.5mm 耳机孔 | 不支持，可使用 Type-C 耳机或转接头 |
| microSD 存储卡 | 不支持 |
| 防水 | 没有官方 IP 防水等级认证 |

小米 8 于 2018 年 5 月 31 日发布，2018 年 6 月 5 日首次开售。中国大陆首发价格为：

| 首发版本 | 最初发布价格 |
|---|---:|
| 6GB＋64GB | **2699 元** |
| 6GB＋128GB | **2999 元** |
| 6GB＋256GB | **3299 元** |


### 3. 小米8 SE

小米 8 SE 的核心配置是 骁龙 710、5.88 英寸 AMOLED 屏幕、164g 机身、3120mAh 电池和 18W 快充。

| 项目 | 小米 8 SE 详细参数 |
|---|---|
| 长 × 宽 × 厚 | **147.28 × 73.09 × 7.5mm** |
| 重量 | **164g** |
| 机身材质 | 玻璃前后面板、金属中框 |
| 配色 | 亮红、亮蓝、金色、深灰 |
| 处理器 | **高通骁龙 710**，10nm 制程 |
| CPU | 八核，2×2.2GHz 性能核心＋6×1.7GHz 能效核心 |
| GPU | **Adreno 616**，最高频率 500MHz |
| 内存 | **4GB / 6GB LPDDR4X** 双通道 |
| 存储 | **64GB / 128GB，eMMC 5.1** |
| 屏幕 | **5.88 英寸三星 AMOLED**，刘海设计、平面显示屏 |
| 分辨率 | **2244 × 1080**，423 PPI，18.7:9 |
| 刷新率 | **60Hz** |
| 屏幕亮度 | 典型 430nit，高亮模式 HBM 600nit |
| 显示功能 | DCI-P3 广色域、HDR、AOD 息屏显示、阳光屏、护眼模式、色温调节 |
| 电池容量 | **3120mAh 典型值 / 3020mAh 最低值** |
| 有线充电 | **QC3.0 快充，标配 18W 充电器** |
| 无线充电 | 不支持 |
| 初始系统 | **MIUI 9.5，基于 Android 8.1**；后续通过系统更新升级 |

相机采用“主摄＋景深辅助”双摄组合：

| 相机项目 | 详细参数 |
|---|---|
| 后置主摄 | **1200 万像素**，f/1.9，1.4μm 像素，支持 Dual PD 双核对焦 |
| 后置副摄 | **500 万像素**，f/2.0，1.12μm 像素，主要辅助人像景深和背景虚化 |
| 光学防抖 | **不支持 OIS** |
| 电子防抖 | 支持 EIS 视频防抖；当年实测中 **4K 录像没有有效电子防抖** |
| 长焦 / 超广角 | 没有独立长焦或超广角镜头 |
| 前置自拍 | **2000 万像素**，支持四合一像素、柔光补光、AI 美颜、人像虚化、自动 HDR |
| 后置录像 | 最高 **4K 30fps**；另支持 1080p、720p 录像 |
| 慢动作 | **720p 240fps、1080p 120fps** |
| 拍照功能 | 人像、HDR、全景、连拍、AI 场景识别等 |

其他功能和接口如下：

| 项目 | 支持情况 |
|---|---|
| 移动网络 | **4G 全网通，不支持 5G** |
| SIM 卡 | 双 Nano-SIM，双卡双待 |
| Wi-Fi | Wi-Fi 5，802.11 a/b/g/n/ac；支持 2.4GHz、5GHz |
| 蓝牙 | **Bluetooth 5.0** |
| NFC | **不支持** |
| 红外遥控 | **支持**，可遥控兼容的电视、空调等家电 |
| 定位 | GPS、A-GPS、GLONASS、北斗、Galileo；没有小米 8 的双频 GPS |
| 指纹解锁 | **后置指纹** |
| 人脸解锁 | 普通前置相机人脸识别，没有小米 8 的红外人脸识别 |
| 扬声器 | 底部单扬声器 |
| 数据接口 | USB Type-C，支持 OTG |
| 3.5mm 耳机孔 | 不支持；原装包装包含 Type-C 转音频转接线 |
| microSD 存储卡 | 不支持 |

小米 8 SE 于 2018 年 5 月 31 日发布，2018 年 6 月 8 日首次开售。中国大陆最初公布的价格如下：

| 首发版本 | 初始发布价格 |
|---|---:|
| **4GB＋64GB** | **1799 元** |
| **6GB＋64GB** | **1999 元** |



### 3. 小米4

核心配置是 5 英寸屏幕、骁龙 801、149g 机身、3080mAh 电池和后置 1300 万像素相机。

| 项目 | 小米 4 详细参数 |
|---|---|
| 长 × 宽 × 厚 | **139.2 × 68.5 × 8.9mm** |
| 重量 | **149g** |
| 机身材质 | 不锈钢金属边框、塑料后盖 |
| 配色 | 雅黑、亮白；另有可更换的装饰后盖 |
| 处理器 | **高通骁龙 801** |
| CPU | 四核 **Krait 400**，最高主频 **2.5GHz** |
| GPU | **Adreno 330**，官方标注频率 578MHz |
| 内存 | 首发 **3GB LPDDR3**；后期另有 2GB 内存版本 |
| 存储 | **16GB / 64GB，eMMC 5.0** |
| 屏幕 | **5 英寸 IPS LCD**，夏普 / JDI 供应，16:9 |
| 分辨率 | **1920 × 1080**，441 PPI |
| 刷新率 | **60Hz** |
| 屏幕功能 | 高灵敏触控、手套模式；后续版本支持阳光屏 |
| 屏幕色域 | 早期官方标注 84% NTSC，2015 年后销售版本升级至 95% NTSC |
| 电池容量 | **3080mAh 典型值 / 3000mAh 最低值** |
| 电池拆卸 | 内置电池，不属于用户可直接拆换设计 |
| 有线充电 | 支持 **高通 QC2.0 快充** |
| 原装充电器 | 提供 5V⎓2A、9V⎓1.2A、12V⎓1A 档位，最高标称输出 **12W** |
| 无线充电 | 不支持 |
| 初始系统 | **MIUI V5，基于 Android 4.4.3**；后续升级至 MIUI 6 等版本 |


相机为前后各一颗：


| 相机项目 | 详细参数 |
|---|---|
| 后置主摄 | **1300 万像素**，堆栈式传感器，**f/1.8**，6 片式镜头 |
| 传感器供应 | 官方后期参数标注为**索尼 / 三星**，不同生产批次可能变化 |
| 自动对焦 | 支持，官方宣传最快约 **0.3 秒** |
| 闪光灯 | 单 LED 闪光灯 |
| 光学防抖 | **不支持 OIS**；提供软件防抖功能 |
| 前置自拍 | **800 万像素**，f/1.8，5 片式镜头，支持美颜 |
| 后置录像 | 最高 **4K 30fps**，另支持 **1080p 30fps** |
| 慢动作 | 支持 **720p 120fps** |
| 前置录像 | 支持 1080p 录像 |
| 其他功能 | HDR、全景、连拍、动态追焦、魔术对焦等 |


其他连接和接口功能如下：

| 项目 | 支持情况 |
|---|---|
| 移动网络 | 有 **3G 版和 4G 版**，取决于具体型号；均不支持 5G |
| 运营商版本 | 曾提供联通 3G、电信 3G、移动 4G、联通 4G、电信 4G 等版本 |
| SIM 卡 | **单 Micro-SIM 卡**，不是双卡 |
| Wi-Fi | **Wi-Fi 5**，802.11 a/b/g/n/ac；支持 2.4GHz、5GHz |
| 蓝牙 | **Bluetooth 4.0** |
| NFC | **不支持** |
| 红外遥控 | **支持**，可遥控兼容的电视、空调等家电 |
| 定位 | GPS、A-GPS、GLONASS、北斗 |
| 指纹识别 | **不支持** |
| 数据与充电接口 | **Micro-USB 2.0**，支持 OTG |
| 耳机接口 | **支持 3.5mm 耳机孔** |
| 扬声器 | 单扬声器 |
| microSD 存储卡 | 不支持 |
| FM 收音机 | 支持 |


小米 4 于 2014 年 7 月 22 日发布，2014 年 7 月 29 日首次开售联通版。最初公布的中国大陆价格为：

| 最初发布配置 | 首发价格 |
|---|---:|
| **3GB＋16GB** | **1999 元** |
| **3GB＋64GB** | **2499 元** |
