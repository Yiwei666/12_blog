# 菜谱

## 1. 瘦肉炒制前处理

**1. 先放肉、姜丝/姜末**

把切好的瘦肉放盆里，先加入姜丝或姜末。

**2. 放料酒、生抽、少量盐、胡椒粉**

两斤瘦肉大概：

- 生抽：2–3勺
- 料酒：1–2勺
- 盐：少量
- 白胡椒/黑胡椒：少许

然后先抓匀 **1–2分钟**，让肉表面有点发黏。

**3. 加入少量清水**

有淀粉了也可以加少量清水，约 **2–3勺**，分两次抓进去。

作用：

- 肉吸收水分后更加嫩；
- 减少炒制过程中水分流失；
- 避免后续二次加热时变柴。

**4. 再放淀粉**

加入淀粉约 **2勺**，继续抓匀，让肉表面形成一层薄薄的浆。

注意：

- 不要放太多淀粉；
- 淀粉过多，炒的时候容易糊锅、发黏。

**5. 最后放食用油**

加入食用油约 **2勺**，抓匀封住水分。

香油可放可不放：

- 如果放，最多 **半勺**；
- 不宜放太多，避免后续炒菜时香油味过重。

---

**简单记：**

> 肉 + 姜 → 料酒/生抽/盐/胡椒 → 抓黏 → 少量水 → 淀粉 → 食用油

腌制 **15–20分钟** 后即可炒。

炒制时：

- 分 **2–3批** 下锅；
- 使用 **中大火快速翻炒**；
- 炒到肉变色、基本熟透即可盛出；
- 不要炒太久，避免瘦肉变柴。

后续炒菜（如青椒、土豆等）时，再将炒好的瘦肉加入翻炒即可。
